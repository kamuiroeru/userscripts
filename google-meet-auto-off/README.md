# Google Meet Auto Mic & Camera Off

Google Meet の参加前画面で、マイクとカメラを自動的にオフにする Tampermonkey 用ユーザースクリプトです。

## インストール

Tampermonkey をインストール済みのブラウザで、次のリンクを開きます。

[Tampermonkey にインストール](https://raw.githubusercontent.com/kamuiroeru/userscripts/main/google-meet-auto-off/google-meet-auto-off.user.js)

Tampermonkey の確認画面で「インストール」を選択してください。

> このリンクは、変更を GitHub の `main` ブランチへ push した後に利用できます。

## 開発時の確認

ローカルで確認する場合は、Tampermonkey の拡張機能の詳細画面で「ファイルの URL へのアクセスを許可する」を有効にしてから、次のファイルをブラウザで開きます。

```text
google-meet-auto-off/google-meet-auto-off.user.js
```

実装は `google-meet-auto-off.user.js` に追加します。Tampermonkey の「更新を確認」から GitHub 上の最新版を取得できます。
